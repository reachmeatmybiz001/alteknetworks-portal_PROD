CUSTOMER LIST UI CHANGE

Change the customer table header from:
Customer | Customer ID | Status

to:
Customer | Customer ID | Created Date | Status

Use:
<span>{customer.createdAt ? new Date(customer.createdAt).toLocaleDateString() : '—'}</span>

and change the row grid from:
'48px 1fr 1fr 1fr'

to:
'48px 1.2fr 1fr 1fr 1fr'

Customer ID is generated by the supplied Lambda in this exact format:
MM-20260001
MM-20260002
AT-20260001
IN-20260001
